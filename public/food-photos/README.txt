FOOD PHOTOS FOLDER
==================

This is where you put photos for your daily foods, if you'd rather use
your own images instead of internet links.

HOW TO USE IT
-------------
1. Put an image file in THIS folder (for example: twinkies.jpg).
   Use .jpg or .png. Keep the filename simple, no spaces.

2. Open the file  daily-foods.csv  (in the "public" folder next to this one).
   In the last column called "photo", type just the filename, like:
   twinkies.jpg

3. Save. The game will automatically show that photo for that food.

USING AN INTERNET LINK INSTEAD
-----------------------------
You can also paste a full web address (starting with http) directly into
the "photo" column. The game will use that link.

LEAVING IT BLANK
----------------
If the "photo" column is empty, the game shows a simple colored placeholder
with the brand name. No photo needed.

TIP: A square-ish photo (about 600x600) looks best in the frame.
